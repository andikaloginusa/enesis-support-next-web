Template Upload Open FKR Pemusnahan

Template Upload Open FKR Pemusnahan.xlsx
Format: .xlsx

Upload massal data pemusnahan FKR berdasarkan kode distributor dan rentang tanggal. Setiap baris mewakili satu pasangan distributor dan periode pemusnahan. Nomor Work Order (WO) dicatat sebagai log audit proses ini.

3 kolom Excel
3 kolom wajib
+1 input manual (Nomor WO)

Kolom Excel

1
Kode Distributor
string
String Wajib
Deskripsi
Kode unik distributor yang melakukan pemusnahan barang FKR.
Contoh
6000435 6000534 6000999
Validasi
Tidak boleh kosong. Angka kode distributor harus terdaftar di sistem (例: 6000435).
2
Start
date
Date Wajib
Deskripsi
Tanggal awal rentang periode pemusnahan (termasuk tanggal ini).
Contoh
2026-08-05
Validasi
Format YYYY-MM-DD. Wajib diisi. Start harus ≤ End.
3
End
date
Date Wajib
Deskripsi
Tanggal akhir rentang periode pemusnahan (termasuk tanggal ini).
Contoh
2026-08-05
Validasi
Format YYYY-MM-DD. Wajib diisi. End harus ≥ Start.

Input Manual (di form, bukan Excel)

Nomor Work Order (WO) di form
Deskripsi
Nomor Work Order sebagai justifikasi dan log audit proses upload ini. Diisi manual di form sebelum upload.
Contoh
WO/IT BUSINESS APPLICATION/26/0056619 WO/IT BUSINESS APPLICATION/26/0056620
Validasi
Tidak boleh kosong. Wajib diisi sebelum submit.

Ringkasan

No Nama Kolom Tipe Wajib Contoh
1 Kode Distributor String Ya 6000435
2 Start Date Ya 2026-08-05
3 End Date Ya 2026-08-05
— Nomor WO (form) String Ya WO/IT BUSINESS APPLICATION/26/0056619

Template Proposal Send Email Ulang

Template Proposal Send Email.xlsx
Format: .xlsx

Upload daftar nomor proposal untuk memicu pengiriman ulang email notifikasi ke approver terkait. Cocok untuk email yang gagal terkirim atau perlu di-resend.

1 kolom Excel
1 kolom wajib

Kolom Excel

1
Nomor E-PROP
string
String Wajib
Deskripsi
Nomor dokumen proposal yang akan dikirim ulang email notifikasinya.
Contoh
121099/MI/MM/JUL/2026
Validasi
Tidak boleh kosong. Harus merupakan nomor proposal yang sudah ada di sistem.

Ringkasan

No Nama Kolom Tipe Wajib Contoh
1 Nomor E-PROP String Ya 121099/MI/MM/JUL/2026

Template Reverse Internasional

Template Reverse Internasional.xlsx
Format: .xlsx

Upload data budget untuk proses reversal internasional secara batch. Setiap baris mewakili satu entri budget yang akan di-reverse. Data budget diperoleh dari sistem budget management.

2 kolom Excel
2 kolom wajib

Kolom Excel

1
budget_id
uuid / string
UUID Wajib
Deskripsi
ID unik budget yang akan di-reverse. Diperoleh dari sistem budget management.
Contoh
42f5572e-01d9-49b2-8866-7d0af30d65de
Validasi
Tidak boleh kosong. Harus merupakan budget_id yang valid dan masih aktif di sistem.
2
budget
decimal / number
Decimal Wajib
Deskripsi
Jumlah nominal budget yang akan di-reverse.
Contoh
1500000 1500000.50
Validasi
Tidak boleh kosong. Harus angka positif. Format desimal menggunakan titik (.)

Ringkasan

No Nama Kolom Tipe Wajib Contoh
1 budget_id UUID Ya 42f5572e-…
2 budget Decimal Ya 1500000.50

Tips Penggunaan Template

  • Download template resmi dari modal upload — jangan ubah struktur kolomnya.
  • Data harus berurutan tanpa baris kosong di antara data.
  • Format tanggal yang didukung: YYYY-MM-DD atau DD/MM/YYYY.
  • Hapus baris contoh/sample sebelum mengisi data asli.
  • Untuk desimal gunakan titik (.), bukan koma (,).
